# 🚫 My AdBlocker

> Учебное расширение для Chrome, которое блокирует базовую рекламу с помощью DeclarativeNetRequest API (Manifest V3).

## 📚 Описание

Это расширение было создано **в учебных целях** и демонстрирует:
- работу с Manifest V3
- использование `declarativeNetRequest` для блокировки рекламы
- управление состоянием включено/выключено через клик по иконке
- динамическое обновление правил иконкой без popup-интерфейса

## 🔧 Функции

- 🔌 Блокировка запросов к рекламным доменам (например, `doubleclick.net`)
- 🎛️ Переключатель ВКЛ / ВЫКЛ (через иконку расширения)
- 🔁 Автоматическая перезагрузка вкладки при переключении
- ❌ Без popup-интерфейса — всё работает в фоне

## 💻 Навыки, использованные в проекте

| Навык                 | Применение |
|-----------------------|------------|
| JavaScript (ES6)      | Логика переключения и работы background |
| Chrome Extensions API | DeclarativeNetRequest, action API |
| Manifest V3           | Новый формат расширений |
| Git & GitHub          | Версионность, документация |
| Debugging             | Проверка правил фильтрации и состояния |
